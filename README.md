## Scenario

An online gift retailer wants to use its sales and customer data to find its best-selling products, understand customer purchasing behaviour, and predict future sales. These analyses need clean transactions, so we profile and repair the data first. Full scenario and questions are in section 1 of the notebook.

## Data source

- **Dataset:** Online Retail II, UCI Machine Learning Repository (id 502)
- **Page:** https://archive.ics.uci.edu/dataset/502/online+retail+ii
- **Download:** https://archive.ics.uci.edu/static/public/502/online+retail+ii.zip
- **DOI:** https://doi.org/10.24432/C5CG6D
- **Licence:** CC BY 4.0 (as stated on the UCI page)
- **Size:** about 1.07 million rows × 8 columns, two Excel sheets (Dec 2009 to Dec 2011)

The notebook downloads the data automatically, so you do not need to download or commit it. The `data/` folder is git-ignored.

## How to run the notebook

### Option A: Google Colab (easiest)

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/MaheyshRamesh/DataEngineering/blob/main/Assignment1_Data_Profiling.ipynb)

Repository: https://github.com/MaheyshRamesh/DataEngineering

1. Click the badge, or upload `Assignment1_Data_Profiling.ipynb` at https://colab.research.google.com (*File > Upload notebook*).
2. Choose **Runtime > Run all**.

No installation or manual download is needed: the notebook checks for missing packages and downloads the dataset itself. Colab storage is temporary, so the download and Excel read (a few minutes) repeat in each new session.

### Option B: run locally

Requires Python 3.10 or newer.

```bash
# 1. Create and activate a virtual environment
python -m venv .venv
# Windows (PowerShell):  .venv\Scripts\Activate.ps1
# macOS / Linux:         source .venv/bin/activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Open the notebook
jupyter lab Assignment1_Data_Profiling.ipynb
```

Then choose **Kernel > Restart Kernel and Run All Cells**.

Run it from the repository root, because the notebook creates a `data/` folder next to itself.

**First run:** downloads about 44 MB and reads the Excel file, which takes several minutes. The raw data is then cached in `data/interim/` and later runs are much faster. To force a fresh download, delete the `data/` folder.

**Outputs:** the cleaned dataset after the Member 1 steps is saved to `data/processed/online_retail_ii_step1.parquet` (git-ignored; regenerated by the notebook).
